# 函数（def）

容器：对数据的封装

类：对方法和属性的封装

函数：对语句的封装

封装的作用：简化代码，不用一段代码反复写

```
#定义函数
def 函数名（参数表）:
    缩进的代码段
    return(函数返回值)
#调用函数
函数名（参数）
无返回值：函数名（参数表）
有返回值：a = 函数名（参数表）
```

局部变量&全局变量

- 某函数的局部变量在函数外无法引用

- 函数内部引用变量，但未定义局部变量，会到全局变量中寻找

- 函数内部定义变量，若用global+局部变量，则定义为全局变量

# 模块（库）

引用模块

```
import（模块）
```

eg:

```

math.sqrt#数学模块中求平方根的函数
```

```
#只调用模块中一小部分使用

#全部导入
```
