# break&continue&return

break:终止整个循环，跳出循环体，执行循环之后的代码

continue：开始下一个数的循环，这个数就执行到continue

return:结束整个函数执行,与 def 函数名配套

```
我现在有个装着123456的数组，如果循环到5就结束整个代码，如果循环到奇数就加入输出结果接着继续找下一个，如果循环到偶数就-1，输出结果。
利用break,continue,return


5：break:直接跳出循环执行循环之后的return
```



```
def process_array():
    A = [1, 2, 3, 4, 5, 6]
    B = []

    for num in A:

        if num == 5:
            break

        # 奇数：加入B，continue跳过本次剩余代码，继续下一个
        if num % 2 != 0:
            B.append(num)
            continue

        # 偶数：-1后加入B
        B.append(num - 1)

    return B


print(process_array())  # [1, 1, 3, 3]
```

# while循环

```
count = 0
while count < 5:
    print(count)
    count += 1          # ⚠️ 别忘了更新条件，否则死循环！
```

while后+条件，满足条件进行循环，即True,不满住执行while循环外的语句

```
while 条件:
    循环体
else:
    # 循环【正常结束】（未被 break 打断）时执行
```

while与else之间，即循环体内有break，直接结束整个循环，不执行else
