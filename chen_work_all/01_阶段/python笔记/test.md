1.判断print()函数会打印什么内容

```
>>> x = 520
>>> x = 880
>>> print(X)
```

打印结果是880。

解释：第一次赋值相当创建了一个命名为x的文档，内容为520，第二次赋值相当于创建了一个内容为880的文档，命名也为x，电脑会提示覆盖原文件所以打印x的内容为880

2.判断print()函数会打印什么内容

```
>>> x, y, z = 3, 4, 5
>>> x, y, z = y, x, z
>>> print(x, y, z)
```

打印结果是4，3，5

解释：第一次赋值相当于创建x,y,z三个文档，内容分别为3，4，5，此时x 就是3，y就是4，z就是5；第二次赋值，相当于将创建三个新文档，分别命名为x,y,z，内容分别填入原y,x,z的内容，保存时电脑提示覆盖原文件

知识点：

赋值和多重赋值覆盖；修改容器内部（列表，字典等内部元素）不覆盖

多次赋值相当于在桌面依次创建文档，输入不同内容，但进行相同命名，电脑最终保留最后一次创建的文档内容

修改容器内部相当于创建一个文档，进行命名，不断修改文件内容，最终文档不覆盖，只是内容改变
