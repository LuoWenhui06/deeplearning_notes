# **（一）解释型语言和编译型语言**

- **解释型语言**：指**不需要编译，直接逐行解释运行**的语言。不用生成. exe可执行文件

  eg:Python、JavaScript、PHP、Ruby

- **编译型语言**：指**需要先编译，再运行**的语言。写完代码 ，用编译器翻译成.exe可执行文件

  eg:C、C++、Go、Rust

- **编译型语言和解释型语言对比**

  **速度**： 解释型比编辑型慢

  **跨平台性**： 解释型比编译型好

# **（二）解释器和编辑器**

- **解释器:** “当场读代码的翻译官”,核心作用是**逐行执行**。

  eg:Python 自带的 IDLE、IPython、Jupyter、Notebook

- **编译器：** “写代码的本子”，核心作用就是**编辑**。

  eg:VS Code、Sublime Text、Notepad++、PyCharm 的编辑界面。

- 所以先安装Python（解释器）再安装Pycharm（编辑器）

# **（三）Python语言的特点**

- **完全面向对象（数据 + 功能 的一个 “整体包”）的语言**

1.**Python 中一切皆对象**，**函数**、**模块**、**数字**、**字符串**等都是对象。

2.完全支持继承（代码复用）、多重继承（多个代码复用）、重载（同名不同参，做不同事）

```
# class造一个模板：父亲
class Father:
    # def定义类的功能：父亲会赚钱
    def earn(self):
        print("赚钱")
# 造一个模板：母亲
class Mother:
    # 母亲会做家务
    def clean(self):
        print("做家务")
# 造一个模板：儿子，同时继承父亲和母亲
class Son(Father, Mother):
    pass  # 儿子啥也不用写，直接继承爸妈的能力
# 用儿子模板，造出一个真正的儿子 s
s = Son()
# 儿子会赚钱（从父亲那继承的）
s.earn()
# 儿子会做家务（从母亲那继承的）
s.clean()
```

3.支持重载运算符（给自定义类也装上加减乘除等符号。），也支持泛型设计（一套代码，适配多种数据类型）

```
# 定义一个模板，名字叫 Person（人）
class Person:
    # 初始化：来了一个人，登记年龄
    def __init__(first, age):#告诉我你的年龄
        first.age = age  # 我给你登记你的年龄
    # 给这个“人” 加上 + 号的功能（重载加号）
    def __add__(first, second):
        return first.age + second.age  # 两个人的年龄相加

p1 = Person(18)#调第二个位置的年龄值为18赋给p1
p2 = Person(20)
print(p1 + p2)
```

```
    from typing import TypeVar, List
# 从 Python 自带的 typing 工具里，import（拿来）两个好用的东西：TypeVar（定义“任意类型”）List（代表列表） 
    T = TypeVar('T')
#赋值
    def print_items(items: List[T]) -> None:
# 定义一个函数，叫 print_items，-> None（这个函数没有返回值）
#items: List[T] （items 是一个列表，里面装的东西全都是 T 类型（任意类型） ）
        for item in items:
# 把列表里的每一个东西挨个拿出来
           print(item)
# 打印每一个东西
    print_items([1,2,3]) 
# 传整数列表 → T 自动变成 int
    print_items(["a","b","c"])
# 传字符串列表 → T 自动变成 str
```

# **（五）Python的优缺点**

#### （1）优点

- 简单、易学
- 免费、开源
- **面向对象**
- 丰富的库
- 可扩展性
- 如果需要一段关键代码运行得更快或者希望某些算法不公开，可以把这部分程序用 `C` 或 `C++` 编写，然后在 `Python` 程序中使用它们

#### （2）缺点

- 运行速度差一点
- 国内市场较小
- 中文资料匮乏
