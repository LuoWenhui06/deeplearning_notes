# 数据类型：容器类型

容器类型：可以装多个数据的数据类型

- 有序/无序（顺序）
- 可重复/不可重复（元素）
- 可变/不可变（创建）

## （一）列表[list]（收纳盒）

![image-20260418131835221](C:\Users\16131\AppData\Roaming\Typora\typora-user-images\image-20260418131835221.png)



1.数据结构原理：动态数组

2.特点

- 有序
- 可重复
- 可变

3.索引

- 正向索引0，1，2·······

- 负向索引·····，-3，-2，-1

4.切片（一次取多个元素）

切片操作

list[start：end：step]

列表[开始：结束：步长]

则从**索引**start取长度到end**[左闭,右开）**，一step一取 



eg:

```
a = [1, 2, 3, 4, 5]

a[1:4]   # [2, 3, 4]（从索引1到4，取元素的第2个到第5个，左闭右开）
a[:3]    # [1, 2, 3]（从索引0到3，取元素的第1个到第4个，左闭右开）
a[::2]   # [1, 3, 5]（从索引0到4，取索引0，2，4，即元素第1个，第3个，第5个，左闭右开）
```

5.添加元素

```
a = [1, 2]

a.append(3)      # 尾部追加元素3
a.insert(0, 10)  # 索引位置0插入元素10
a.extend([4,5])  # 尾部加入列表[4，5]
```

6.删除元素

```
a = [1, 2, 3, 4]

a.remove(2)   # 删除指定元素2
a.pop()       # 删除最后一个
a.pop(1)      # 删除指定索引位置1
del a[0]      # 删除指定索引位置0
```

7.改元素

```
a = [1, 2, 3]
a[1] = 100   #将索引位置1的元素2改为100
```

8.访问元素

```
a[0]   #访问索引位置0的元素
```

9.遍历（难）

```
a=[1,2,3,4]
for x in a:  #把在a中的元素用x拿出来
    print(x)
```

```
for i in range(len(a)):  #索引range(len(a))，len(a)=4
    print(i, a[i])
```

10.常用函数

- len(a)        # 长度
- max(a)        # 最大值
- min(a)        # 最小值
- sum(a)        # 求和
- a.sort()      # 排序（改变原列表）
- a.reverse()   # 反转

11.嵌套列表

每一个元素是一个列表



**元组**（不可修改的列表）

1.特点：

- 有序
- 可重复
- 不可变

2.单个元素必须有逗号

eg:t=(1,)

3.可作为字典的key

4.元组本身不能变，但是作为元素的列表的元素可变

## （二）字典[dict]（带标签[key]的柜子）

数据结构原理：哈希表

- 无序(python3.7官方有插入顺序，但仍无列表的索引顺序)
- 不可重复
- 可变（但key必须是不可变类型）

3.写法

```
d = {"name": Luo, "age": 2}
```

4.查

```
d = {"name": "Tom", "age": 18}

print(d["name"])   # Tom
或者
d.get("name")
```

5.增/改

```
d = {}

d["name"] = "Tom"    # 新增key
d["name"] = "Jerry"  # 修改value
```

6.删

```
d = {"a": 1, "b": 2}

del d["a"]
d.pop("b")
d.clear()
```

7.遍历

- 遍历key

  ```
  for k in d:
      print(k)
  ```

- 遍历value

  ```
  for v in d.values():
      print(v)
  ```

- 同时遍历

  ```
  for k, v in d.items():
      print(k, v)
  ```

8.嵌套

```
students = {
    "Tom": {"score": 80},
    "Jerry": {"score": 90}
}
```

## （三）集合[set]（去重后的物品堆）

1.数据结构原理：哈希集合

2.特点

- 无序
- 不可重复
- 可变

3.写法

```
s = {1, 2, 3}
或者
s = set([1, 2, 3])
```

4.空集合

```
s = {}       # 这是字典
s = set()    # 这是集合
```

5.集合的查只能遍历（没有索引）

6.添加元素

```
s = {1, 2}
s.add(3)  #添加元素3
```

7.删除元素

```
s.remove(2)   # 删除元素3
```

因为无序，所以可以随机删除

```
s.pop()
```

8.数学集合运算

- 求交集

```
a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)
```

- 求并集

```
print(a | b)
```

- 求差集

```
print(a - b)  #a有b没有
```

- 对称差集（不重复的部分）

```
print(a ^ b) 
```
